# Exercices GitHub

Ce dépôt sert à pratiquer les issues, les branches et les pull requests.

## Issue

Une issue décrit une question, une tâche ou un problème. Fermer l'issue quand le travail est terminé.

## Branche et pull request

1. Créer une branche depuis `main`.
2. Modifier un fichier et créer un commit explicite.
3. Ouvrir une pull request vers `main`.
4. Vérifier le diff : seuls les changements prévus doivent apparaître.
5. Fusionner la pull request, puis supprimer la branche devenue inutile.

Dans un projet partagé, suivre les règles de revue et les vérifications du projet.

## Discussions

Pour aider sur un projet, répondre aux questions de sa catégorie Q&A avec une solution vérifiée et reproductible. L'auteur de la question ou un responsable du projet peut accepter la réponse.

## Achievements

Les badges sont attribués par GitHub. Une action réalisée ne garantit pas leur affichage immédiat.
